## Notes for next session

- **`.env` password escaping (2026-09-22 incident):** python-dotenv
  treats `\` literally, so a shell-quoted password like `foo\!` in
  `.env` reaches the SDK with a real backslash and CIAM returns
  `error=invalid_username_password`. If auth fails with that exact
  error while web login works, check `.env` for stray backslashes
  before assuming credential rotation. Fix: strip the `\` — do not
  wrap the value in quotes either, dotenv strips single/double
  quotes but not backslashes.
- After code changes here, the registered MCP in other windows keeps
  serving the old code (and old env) until a `/mcp` reload from the
  Claude Code client or a fresh session.
- All operational knowledge (endpoint shapes, PATCH body, POST+PATCH
  create dance, calendar mutation quirks, auth) lives in
  `docs/patterns.md`, `docs/endpoints.md`, `docs/open-questions.md`.
